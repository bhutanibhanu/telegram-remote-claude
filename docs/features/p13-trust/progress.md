## Tasks

### T-AUDIT — durable body-free audit trail
- **Files:** new `claude_tg/audit.py`; `claude_tg/config.py` (audit path/size knobs, default next to `CLAUDE_STATE_FILE`); `claude_tg/engine/engine.py` (`on_tool_request` hook — the chokepoint that sees auto-allow/grant/yolo + holds + verdicts, so it catches what `resolve_callback` would miss); `claude_tg/engine/__init__.py`; `claude_tg/bot.py` (`/audit` cmd + COMMAND_MENU + HELP, `ChatBoundSink` stamping chat_id); `claude_tg/stream_session.py` (wire the sink; attach/switch/watch records).
- **Accept:** every security-relevant event (tool approve/deny with tool name + `safe_input_summary` + decision + chat id + ts; plan approve/reject; attach/switch/`/watch`; bypass/policy) appends a body-free line to an append-only JSONL audit log (atomic, **0600**, size-bounded rotation). **SB3: structural** — `AuditEvent` has NO body-bearing field; the sink only ever receives already-safe strings; **secret_scan stays green** on any sample. `/audit` (SB1) shows the recent tail, body-free. **RB1: an audit-write failure NEVER breaks a turn** (best-effort, logged). Default-on but **non-breaking** (no-op `audit_sink=None` keeps the 1288 floor + behavior unchanged when off/unconfigured).
- **Tests:** AuditEvent has no body field (structural); the log is 0600 + atomic + rotates; a planted secret/raw-body never appears (SB3, + a secret_scan-green fixture); the engine hook records allow/deny/grant/yolo/hold outcomes; `/audit` SB1-gated + body-free + menu/HELP lock-step; audit-write failure → turn still completes (RB1); no-op default = behavior unchanged.

### T-BASH — Bash policy guardrail (the C2 follow-up)
- **Files:** new pure `claude_tg/bash_policy.py` (`classify_bash(command) -> (matched, pattern, severity)`, conservative built-in denylist: `rm -rf /`, `curl|sh`/`wget|sh`, force-push, `mkfs`/`dd of=`, fork bomb, `chmod 777`, secret-store reads — scan the RAW command, not the 160-char summary); `claude_tg/config.py` (`BASH_POLICY_MODE`, default `flag`); `claude_tg/engine/engine.py` (consult ADDITIVELY in `on_tool_request`); `claude_tg/engine/types.py` (`PermissionEvent.bash_flag`); `claude_tg/render.py` (⚠️ + matched-pattern line; drop `[Allow for session]` for a flagged command).
- **Accept:** `flag` (default) → a matched dangerous Bash command escalates the existing prompt (⚠️ + the matched pattern), forces a deliberate `[Allow once]` (NO `[Allow for session]`), and **re-prompts even under an active session-grant/yolo for that matched command** (the deliberate C2-residual closure — a guardrail that beats the bypass for dangerous commands only). `deny` → matched command hard-denied (auto). `off` → current behavior. **FAIL-CLOSED:** a matcher raise / ambiguous match → escalate (flag) or deny, NEVER silent-allow. **Additive:** the policy NEVER converts a would-prompt/would-deny into an auto-allow (mutation-probe this). Safe default = `flag` (strictly safer, non-breaking for non-matching commands). Every flagged decision is audited (ties to T-AUDIT).
- **Tests:** `classify_bash` matches the denylist + does NOT match benign commands (false-positive guard) + scans raw command; flag mode escalates + drops session-allow + re-prompts under yolo for a matched command; deny mode auto-denies; off = unchanged; **fail-closed** (matcher raises → escalate/deny); **additive mutation-probe** (policy must never turn a would-prompt into an allow — break it → a test fails); flagged command produces an audit record.
